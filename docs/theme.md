Design Guidelines

The UI should feel like a fantasy battle strategy game

Use bright backgrounds with colorful accents

Cards should have rounded corners and soft shadows

Buttons should use the primary accent color (#7C3AED)

Auction bids should highlight using gold (#FBBF24)

Combat events should highlight using red (#EF4444)

Use clean grid layouts and simple spacing

Keep the interface minimal, readable, and visually balanced

Required UI Components

Design the following components:

Team Dashboard

Shows team coins, owned characters, and status.

Auction Interface

Displays current character being auctioned.

Shows live bids and bidding controls.

Character Cards

Display character stats such as HP, damage, abilities, and role.

Deck Management Panel

Allows teams to view and manage their selected characters.

10 × 10 Battlefield Grid

Interactive grid where characters are deployed.

Battle Simulation Screen

Displays character movement, combat interactions, and battle progress.

Leaderboard

Shows team rankings, wins, and points.

Battlefield Grid Design

The battlefield should contain a 10 × 10 grid with clearly visible cells.

Design rules:

Each grid cell should have soft borders using #CBD5E1

The grid should look like a tactical board

Team deployment zones should have slightly different background shades

Characters should appear as cards or icons placed inside grid cells
